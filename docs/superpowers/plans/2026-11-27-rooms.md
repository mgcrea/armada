# Rooms Implementation Plan

> Implement this plan inline, task by task, in one branch. Run the focused tests named in the task, and `make -C apps/apple build` once the app target is involved. Run the full Apple suite once, in Task 6. Do not spawn an implementer per task.

**Goal:** A shared log on Armada's MCP server so one session can start a seat per provider and have them compare findings, without delivering those findings as turns.

**Architecture:** A pure `Room` model and a `RoomDirectory` actor live in `ArmadaMCP`, behind a `RoomStore` protocol, the way `ScheduleStore` sits behind the schedule tools. The tool table grows four tools. `armada_room_round` calls the existing `MessageSender` with one fixed sentence. The app wires the directory at `AppInfo.supportDirectory/rooms` and posts one notification when every seat has posted done.

**Tech Stack:** Swift 6.2, Swift Testing, the existing `MCPKit` tool table. No new package and no pbxproj edit. New Swift files under `Packages/ArmadaMCP` are already on `SWIFT_SRC`.

**Spec:** [docs/superpowers/specs/2026-11-27-rooms-design.md](../specs/2026-11-27-rooms-design.md). Read it first. Every limit, the brief, the nudge, and the nudge table below are copied from it. If the two disagree, the spec wins and this plan is updated.

## Global Constraints

- A post never reaches `MessageSender`. Only `armada_room_round` does, and only with `RoomNudge.text`.
- `armada_start_session` with `room` and `seat` does not call the starter until the room and the seat have been accepted. The `prompt` it passes is the stored brief.
- `SessionStarter`, `StartSessionRequest` and `MessageSender` do not grow room fields.
- `Tools.table` gains `rooms:` with a default of `UnavailableRoomStore()`, so every existing call site keeps compiling. The app passes the real store.
- Voice: `armada_room_read` joins `SupervisorArguments.readTools`. `armada_room_open`, `armada_room_post` and `armada_room_round` join `deniedTools`. They are not added to voice's `writeTools`.
- Files stay 0600 and the directory 0700. A file this build cannot decode is moved aside, as `StoreFile` does, and is not overwritten.
- Tool descriptions have to pass `ToolsTests.descriptionBudget` (the tool's JSON under 1,400 bytes). Shorten the description, not the behaviour, if one fails.
- Commit by explicit path. Conventional messages, as in `git log`.

## Review Focus

1. **The nudge contains no post.** A room whose posts include `rm -rf /` still sends only `RoomNudge.text`. Test in Task 4.
2. **A bad room does not open a terminal.** `room` set and the room missing, closed, or paired with `prompt` or `resume`: `FakeSessionStarter.requests` stays empty. Test in Task 5.
3. **The caller cannot rewrite the brief.** `start` with `room` and `seat` and no `prompt` passes the stored brief as `StartSessionRequest.prompt`. Test in Task 5.
4. **Two sessions containing the marker bind neither.** Test in Task 1.
5. **A closed room does not block a wait.** `wait_seconds: 240` on a closed room returns in the test's poll, with `closed: true` and `timedOut` absent or false. Test in Task 4.
6. **A file this build cannot read is moved aside**, and a later open of that name writes a new file without touching the `.bak`. Test in Task 2.
7. **Voice cannot call the three write tools**, and can call `armada_room_read`. Test in Task 6.

### Task 1: The room model

**Files:**
- Create: `apps/apple/Packages/ArmadaMCP/Sources/ArmadaMCP/Room.swift`
- Create: `apps/apple/Packages/ArmadaMCP/Tests/ArmadaMCPTests/RoomTests.swift`

**Interfaces — Produces:**
- `public struct Room: Sendable, Equatable, Codable` with `version` (always 1), `name`, `question`, `openedAt: Date`, `closedAt: Date?`, `round: Int`, `seats: [Seat]`, `posts: [Post]`.
- `Seat`: `seat`, `vendor`, `marker`, `projectPath: String?`, `sessionID: String?`, `promptAwaitsSend: Bool`, `headless: Bool`. `var done: Bool` is true when some post has this `seat` and kind `done`. No stored done flag.
- `Post`: `id` (`p1`, `p2`, …), `at: Date`, `seat`, `kind`, `text`, `replyTo: String?`.
- `public enum RoomKind: String, Codable, CaseIterable` — `note`, `finding`, `question`, `blocked`, `done`.
- `public enum RoomRules`:
  - `static func nameRefusal(_:) -> String?`, `seatRefusal(_:) -> String?`, `questionRefusal(_:) -> String?`, using the spec's patterns and caps. Name and seat match ASCII `a-z`, `0-9` and `-` only (not Unicode `isLowercase`). Question trims whitespace/newlines before checking length (1 to 2,000) and uses the control-character rule in `Tools.messageRefusal` (newline and tab allowed).
  - `static let maxSeats = 8`, `maxOpenRooms = 20`, `maxPosts = 200`, `pageSize = 30`, `markerBytes = 8`, `keepClosedDays = 7`.
  - `static func marker() -> String` — eight lowercase hex digits.
- `public enum RoomBrief { static func text(name:seat:marker:question:) -> String }` — the spec's brief, verbatim, with the four substitutions. No other wording.
- `public enum RoomNudge { static func text(name:round:) -> String }` — the spec's nudge, verbatim.
- `public struct RoomCandidate: Sendable, Equatable` — `id`, `vendor`, `cwd`, `containsMarker: Bool`, `isSubagent: Bool`.
- `Room.bind(_ seat: Seat, candidates: [RoomCandidate]) -> Bind` where `enum Bind { case unchanged, bound(String), ambiguous(project: String) }`. Match `vendor`, `containsMarker`, `isSubagent == false`, and `cwd` equal to `projectPath` or inside it on whole path components (like `ProjectPath.contains`, never raw string prefix). Compare with `realpath` when both resolve, else the strings without a trailing slash. Zero matches → `.unchanged`. One → `.bound`. Two or more → `.ambiguous`. A seat with `sessionID` already set returns `.unchanged` and ignores candidates. A seat with `projectPath == nil` returns `.unchanged`.
- Mutating methods on `Room`, each returning `String?` (a refusal) or `nil`:
  - `post(seat:text:kind:replyTo:at:) throws` is the wrong shape. Return `Result<Post, String>` via `func append(...) -> String?`, trimming `text` before storing and validating with `Tools.messageRefusal`, and append on nil. `allDone` before and after is how the caller computes `becameAllDone`.
  - `func noteSession(seat:projectPath:sessionID:promptAwaitsSend:headless:) -> String?`
  - `func apply(_ bind: Bind, to seat: String)` — `.bound` sets `sessionID` when it was nil. `.ambiguous` and `.unchanged` change nothing.
  - `func beginRound() -> String?` — refuses when `closedAt != nil`, else increments `round`.
  - `func close(at: Date)` — sets `closedAt` if nil.
- `var allDone: Bool`, `func page(after: String?) -> (posts: [Post], cursor: String?, truncated: Bool)`. `after` nil starts at the beginning. More than 30 posts sets `truncated` and returns the first 30. `cursor` is the last post `id` returned, or `after` when no new posts follow `after`. An unknown `after` (including `""`) is a refusal the tool reports; the model method can return nil for that and the tool checks.

Put the refusal sentences in `RoomRules` so the tests pin them:
- empty question → `"The question is empty."`
- question over 2,000 → `"The question is N characters; the limit is 2000."`
- bad name → `"A room name is 1 to 40 characters of lowercase letters, digits and hyphens."`
- bad seat → `"A seat name is 1 to 20 characters: a lowercase letter, then letters, digits and hyphens."`
- duplicate seat → `"Seat <seat> is listed twice."`
- no seats → `"Name at least one seat."`
- more than 8 → `"A room has at most 8 seats."`
- bad vendor → `"Seat <seat> has vendor \"<v>\", not claude, codex, grok or antigravity."`
- unknown seat on post → `"Seat <seat> is not in this room."`
- closed on post → `"Room <name> is closed."`
- 200 posts → `"Room <name> has 200 posts, which is the limit."`
- bad reply → `"reply_to <id> is not a post in this room."`
- post text reuses `Tools.messageRefusal` unchanged.
